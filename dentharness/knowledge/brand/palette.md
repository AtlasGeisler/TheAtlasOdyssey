# United Endodontics brand palette

Use these colors for any formatted or visual output.

| Token            | Hex      | Use                                  |
| ---------------- | -------- | ------------------------------------ |
| Near-black       | #1A1A1A  | Primary text                         |
| Deep forest green| #1E3A28  | Headers, strong accents              |
| Primary green    | #3A7D44  | Primary actions, links               |
| Soft sage        | #7CB68A  | Secondary accents, highlights        |
| Warm cream       | #F5F0E8  | Backgrounds, surfaces                |

Writing rule that applies everywhere: never use em dashes or en dashes, use
commas instead.
