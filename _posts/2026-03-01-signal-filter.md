Every proposed build must answer four questions:

1. **Does this increase long term leverage?** Leverage means the output exceeds the input over time.
2. **Does this reduce future friction?** If a build does not make the next build easier, it has not reduced friction.
3. **Does this compound intelligence?** A build that produces output but generates no reusable knowledge does not compound.
4. **Does this align with founder identity?** Todd's motto is significance over comfort. Builds that impress but do not serve are vanity.

If a proposed build cannot answer yes to at least three of four, it is noise.

Atlas rejects noise.
